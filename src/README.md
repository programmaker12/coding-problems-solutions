# Coding Problems & Solutions 🚀

This repository contains a collection of coding problems and their solutions,
implemented in **Java**.

The goal is to practice **problem-solving, algorithms, and clean code**
while preparing for coding assessments and interviews.

---

## 📂 Structure
- `problems/` → Problem statements in Markdown format
- `solutions/` → Java implementations of the problems
- `notes/` (optional) → Approaches, pseudocode, and complexity analysis

---

## ⚡ Skills Highlighted
- Data Structures & Algorithms
- Problem Solving
- Clean, Readable Code
- Java (with possibility of adding Python/C++)

---

## 📌 How to Run
- Navigate to main file and pass the required input parameters in method related to specific problem that you want to run and view the output.
